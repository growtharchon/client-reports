Context

Client: True Form Pilates, Saline MI — trueformpilates.com

What they do: Private, duet, and trio apparatus Pilates (reformer, Cadillac/tower, ladder barrel). Instructor/owner is Carly. Brand line: "Serious Pilates. Zero Pretense."

Current state: Technical SEO is solid (Lighthouse 96-100 across the board). Static Astro site on Vercel. What's missing is SEO-optimized copy on existing pages and the content layer (location pages + blog).

Goal today: Draft SEO copy for existing pages, build location pages, the "near me" page, and 10 blog posts. Deploy everything on a separate demo site for review.

1 Existing Page SEO Audit

Review every page on the live site and draft improved SEO titles, meta descriptions, and H1 headlines. The home page is the priority — it currently has no real SEO title or keyword-targeted headline.

What to deliver

  • For each page on the site (home, about, services, contact, studio policies, etc.), draft:
    • SEO title (under 580px in Arial 20px — roughly 55-60 characters)
    • Meta description (under 155 characters)
    • H1 headline recommendation (if the current one isn't keyword-targeted)
  • Focus the home page on the primary keyword: pilates saline mi or pilates studio saline michigan
  • The brand tagline "Serious Pilates. Zero Pretense" can stay on-page, but the H1 and title tag should carry the target keyword
Format: Put this in a simple table or doc that I can review at a glance — page name, current title, proposed title, proposed meta, proposed H1.

Blog post guidelines

  • Target 800-1,200 words per post (these aren't complex topics)

  • Use TrueForm's voice: direct, knowledgeable, no-nonsense. Carly is a real practitioner, not a content farm

5 Workflow & Order of Operations

  1. Existing page SEO audit — draft titles/metas/H1s for all current pages. Send to Jack for review.
  2. One location page template (Ann Arbor) — build the full page on the demo site. Send to Jack before doing the other four.
  3. Once approved: replicate for the other 4 location pages + the Near Me page.
  4. Blog posts — use our AI content workflows (the system Darko walked through) to draft all 10. These are straightforward topics. If you get stuck on the AI tooling, flag it and we'll find a workaround — none of these topics are complex enough to need manual research.
  5. Deploy everything on the demo Vercel site.
